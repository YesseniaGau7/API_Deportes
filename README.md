# API 2 - Deportes

API REST elaborada para la actividad B10. API 2.

## Tecnologías

- Node.js
- Express
- JSON
- HTML
- CSS
- JavaScript

## Instalación

Abre una terminal dentro de la carpeta del proyecto y ejecuta:

npm install

## Ejecutar

npm start

Después abre:

http://localhost:3000

## API

Todos los deportes:

GET http://localhost:3000/api/deportes

Un deporte:

GET http://localhost:3000/api/deportes/1

Agregar:

POST http://localhost:3000/api/deportes

Actualizar:

PUT http://localhost:3000/api/deportes/1

Eliminar:

DELETE http://localhost:3000/api/deportes/1
